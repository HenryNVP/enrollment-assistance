Supporting Documentation
Either submitting the Personal Information Change Request via Online or PDF form [pdf], Be sure to follow all instructions carefully. you will be required to submit supporting documents to validate the change. These documents must be government-issued documents, such as a court order, driver’s license, social security card, or passport.
How to submit your PDF form
You may submit this form via email to records-regist@sjsu.edu, dropping off in-person at Window R at Student Services Center.
Important Information:
Primary Name(Legal Name)
- Will be used on all official university documentation (official/ unofficial transcript), the SJSU ID (Tower) Card, and any documentation involving financial aid or student accounts.
- Will be used on diplomas unless a Diploma Name has been added to the student’s record.
- Must be used when conducting official university business.
- If an update or correction is needed, submit Personal Information Change Request Online. Be sure to follow all instructions carefully.
Preferred Name
San Jose State University recognizes that members of our community may choose names other than their legal names to identify themselves. SJSU allows preferred names - as long as the name is not used to misrepresent or evade legal obligations. The university reserves the right to remove a preferred name if it is being used improperly.
- Current students can set up a “preferred name” on MySJSU
- The Preferred name will only be seen on Class Rosters, Grade Rosters, CANVAS, and the Advisor Center.
Diploma Name
Starting Spring 2022, students may use a name other than their Primary (legal) Name on their diploma. Students must follow the guide to add a Diploma Name in their MySJSU [pdf] by posted deadlines, otherwise the Primary (legal) Name will be used.
Note:
- The Diploma Name will be used exclusively for diplomas.
- To update or correct the Primary (legal) Name, submit the Personal Information Change Request Online. Be sure to follow all instructions carefully.
- For current graduates: Once a diploma is printed with the Diploma Name, additional diplomas can be obtained for a fee. See options to order your duplicate diploma.
Have Additional Questions?
